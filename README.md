## About

I'm a Physics student who ended up as a full-stack, game, and mobile developer — turns out the two aren't as far apart as they sound. By day I'm in the lab; by night I'm building things at **Bombastudio**.

**Currently working on**
- 🎮 **Talu Engine** — a custom game engine written with a language called *wolflang*
- 🚗 **Airsence** — a vehicle reservation system, Laravel on the back-end
- 🌍 **Promptme4Better** — an Erasmus+ project on AI literacy
- 🔮 **Meowstick** — an AI-powered tarot reading app, already shipped

**Open to collaborating on:** Web3 / on-chain ideas, game dev, or anything that needs solid AI integration woven in.

**Could use a hand with:** optimizing Talu Engine, or thinking through Rust / C++ architecture for it.

**Ask me about:** Laravel, Flutter, React/Vue, game engine architecture, or how to end up a full-stack dev while majoring in Physics.
